## Leçons
1. **Garder les moments humains**, même hors sujet : l'histoire de Meg, les blagues sur les notes. Harry rallonge l'interview pour eux. Moi, je coupais tout ce qui ne parlait pas du plat.
2. **Couper l'info secondaire de la VO** (les 3 adresses) pour arriver plus vite aux invités.
3. **L'ordre d'une interview n'est pas figé** : une note drôle peut ouvrir l'interview.
4. **Fin :** Harry termine sur l'invité, sans récap dans Premiere. Le carton résultat est peut-être ajouté dans CapCut : à demander.
